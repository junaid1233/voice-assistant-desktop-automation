# BluePilot — Complete Command List

Product: **BluePilot** by Bluexech  
Wake word: **bluepilot** (from `.env`)

You can also say greetings first: `Hey BluePilot…`, `Hi…`, `Okay…`

---

## 1. Apps — Open / Close

| English | Roman Urdu |
|---|---|
| Open Chrome | chrome kholo |
| Close Chrome | chrome band karo |
| Open Notepad | notepad kholo |
| Close Notepad | notepad band karo |
| Open Calculator | calculator kholo |
| Close Calculator | calculator band karo |
| Open VS Code | vscode kholo |
| Close VS Code | vscode band karo |
| Open Cursor | cursor kholo |
| Close Cursor | cursor band karo |
| Open Slack | slack kholo |
| Close Slack | slack band karo |

**Aliases**
- Open = `launch` / `start` / `run`
- Close = `kill` / `terminate`

## 7. Exit Assistant

| English | Roman Urdu |
|---|---|
| Exit / Quit / Goodbye | band karo |

**Important**
- `chrome band karo` → closes Chrome only
- `band karo` (no app name) → exits BluePilot
